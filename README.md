# Frantic #146 — Nitrosend welcome email, remixed

Delivery for Frantic bounty #146: "Like Nitrosend's email templates on v0, then make one of the designs yours and send it."

## What this is

A hand-built welcome email for Rohit Rajput (freelance Digital Specialist), remixed from the Tally Forms welcome email on Nitrosend's email-examples page
(`nitrosend.com/email-examples/e/tally-forms-welcome-195f91f2d53c10c5` — plain-text, conversational style, one clear call to action). The design was rebuilt from scratch for his brand, with a single CTA to his portfolio.

## Honest notes

- **v0 templates:** the v0 template library contains **no Nitrosend email templates**. Verified live twice on 2026-11-10 (cloud browser + device browser): searching "nitrosend" returns "No Templates Found"; searching "nitro" returns one unrelated result. There was nothing to like and no v0 template to remix. Nitrosend's own docs confirm the v0 integration is an MCP preset inside v0 chat, not library templates.
- **The send:** the remixed email is sent live via Nitrosend to the account owner's own inbox as a test send. The send receipt (`message.json`) is added here after the send.
- **Files:** `template.html` (the email), `report.md` (full delivery report), `evidence.json` (machine-readable evidence), `message.json` (the live send receipt).
